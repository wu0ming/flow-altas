# 图谱模型与运行方式

## 记录

| 对象 | 内容 |
| --- | --- |
| 节点 | 稳定 ID、名称、类型、工作／生活／通用范围、说明、图标 |
| 流程 | 处理域的名称、分类与图标 |
| 连线 | 起终点、方向、内容、通道类型与名称、处理域及使用状态 |
| 跨域端点 | `fromDomain`、`toDomain` 可分别指定端点所在层，留空时使用连线所属流程 |

二维总览保持节点位置稳定。放大后出现编辑所需的信息。三维分层以点线连接同一节点在多层的显示点，带箭头的连线表示实际的数据流。三维放射视图以选定节点为中心按连接步数排列。

## 源码

| 路径 | 内容 |
| --- | --- |
| `web/` | 页面、二维和三维渲染、图谱操作、表单与主题 |
| `server/seed.mjs` | 虚构演示数据 |
| `server/api.mjs` | 图谱及导出接口、批量编辑、撤销和 MCP |
| `scripts/` | 构建、本地预览及验证 |
| `.agents/skills/flow-atlas-maintenance/` | 助手维护工作流 |

读取与写入都按已核验的用户身份分区。保存使用图谱版本与 R2 条件写入拦住过期修改。新节点和同批连线一次校验、一次落盘。撤销保留最近一次成功修改前的版本，导出文件包含当前图谱。

## 生产运行

本地预览会模拟用户身份与 R2。生产部署从可信入口接收用户身份，请把 Worker 放在完成验证并覆写身份头的入口后面。部署清单 `.openai/hosting.json` 声明了 R2 和 MCP 能力。根据目标站点补充该环境使用的项目标识，再执行构建和平台部署。MCP 与页面共享图谱存储，维护前应先读当前版本。
